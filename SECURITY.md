# Security policy

## Scope

This policy covers the Woodcock Dance source code and the Windows x64 release
packages in this repository.

Woodcock Dance is an offline desktop application. It does not provide a
network service, download content, execute shell commands, or send telemetry.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public GitHub Issue.
Use a private GitHub security report or another private contact method to the
repository owner. Include the affected version, Windows version, reproduction
steps, impact, and any minimal test file needed to reproduce the issue.

If the report involves an image file, do not attach it publicly. Describe the
file properties first and share it only through a private channel.

## Response

Reports will be acknowledged after review. A fix may be published as a new
release, together with a short description of the affected version and the
mitigation. This project does not currently offer a bug bounty.
